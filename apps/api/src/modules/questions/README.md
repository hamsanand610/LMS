# questions module

The question bank: every question the institute has written, in one place (journey J-06).

| Aspect      | Detail                                                                                                                                                                                                                                                                            |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Routes      | `GET/POST /questions`, `GET/PUT/DELETE /questions/:id`, `GET /questions/:id/versions`, `POST /questions/:id/status`, `POST /questions/:id/validate`, `POST /questions/:id/validation`, `POST /questions/:id/practice`, `GET /questions/import/template`, `POST /questions/import` |
| Permissions | `questions:read` (scope `all` or `own`), `questions:create_own`, `questions:manage`, `questions:import`; the practice endpoint needs `practice:manage`                                                                                                                            |
| Types       | Multiple choice with one or several answers, true/false, written, and coding. The type is fixed once a question is saved (`question_type_locked`), because a paper that used it must stay meaningful                                                                              |
| Editing     | `PUT` replaces the whole question: the editor always sends everything, and calling it `PATCH` would have been a lie. Each save writes a version row, so what a learner saw can still be explained                                                                                 |
| Scope       | A caller with only `questions:create_own` sees and edits their own work, whatever they ask for; `questions:manage` reaches everything                                                                                                                                             |
| Answers     | `GET /questions/:id` is staff-only. The learner-facing copy comes from the assignment or test module with `forLearner`, which strips the correct options, the explanations, the hidden cases and the reference solution                                                           |
| Coding      | Languages, starting code per language, a reference solution, limits, and test cases marked sample or hidden. A hidden case is never returned by this module, to anybody                                                                                                           |
| Validation  | A coding question cannot be published until its own reference solution passes every case (`question_not_validated`). With a server-side driver the API runs it; with the browser driver the editor runs it and posts what happened (ADR-0011)                                     |
| Import      | CSV or TSV of objective questions, with a template. A dry run writes nothing and reports every unusable row with its line number and the reason; a title already in the bank is skipped, not duplicated (plan AC-06.1)                                                            |
| Retiring    | A question in use can be retired but not deleted (`question_in_use`): papers that already contain it keep working, and it simply leaves the pickers                                                                                                                               |
| Practice    | A published coding question can be put in the practice catalogue with a point value; the catalogue is a view over these rows rather than a second set of problems                                                                                                                 |
| Events      | `question.published`, `question.retired`                                                                                                                                                                                                                                          |
| Audit       | `question.created`, `question.updated`, `question.published`, `question.retired`, `question.deleted`, `question.validated`, `question.imported`, `question.practice_changed`                                                                                                      |
| Tests       | `test/assessment.e2e-spec.ts` (authoring, versioning, the import error report, learner-facing stripping, trainer scope)                                                                                                                                                           |

Coding questions are the only type that needs code to run, and no code runs here: see ADR-0007 and
the execution module.
