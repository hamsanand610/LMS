# placement module

Companies, placement drives and learners' applications (F-19, ADR-0014).

| Aspect      | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Routes      | Companies: `GET /companies`, `GET /companies/:ref`, `GET /companies/kit-candidates`, `POST /companies`, `PUT/DELETE /companies/:id`, `PUT /companies/:id/kit`, `PUT/DELETE /companies/:id/favourite`. Drives: `GET /drives`, `GET /drives/:id`, `POST /drives`, `PUT/DELETE /drives/:id`, `POST /drives/:id/status`, `GET /drives/:id/applications`, `POST /drives/:id/applications/export`, `GET /drives/:id/applications/:applicationId/resume`, `PATCH /drives/:id/applications/:applicationId`, `POST /drives/:id/apply`, `POST /drives/:id/withdraw`. Learner: `GET /me/placement` |
| Permissions | `placements:read`, `placements:manage` (placement staff and administrators), `placements:apply` (learners)                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Eligibility | Worked out on the server from the drive's rules and the learner's record (`eligibility.spec.ts`); a learner applies only while the drive is open and they are eligible                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Applicants  | Placement staff see a drive's applicants with their batches and attendance. A résumé opens through a five-minute signed link, audited `placement.resume_viewed` (ADM-07); the applicants export as CSV, audited `placement.applicants_exported`                                                                                                                                                                                                                                                                                                                                         |
| Audit       | Company and drive changes, each stage change of an application (the learner is told), résumé links, exports                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Tests       | `test/engagement.e2e-spec.ts` (applying and withdrawing), `test/admin-operations.e2e-spec.ts` (résumé and export, refused to trainers and learners)                                                                                                                                                                                                                                                                                                                                                                                                                                     |
