# Stack and version pins

Pinned at Phase 1 setup (13 September 2026). Majors change only at phase boundaries with an ADR.

Not adopted: an AI provider SDK (Phase 7 calls Gemini over HTTPS with the platform's own `fetch`, ADR-0024), LangChain, LangGraph and LangSmith (kept out of Phase 7, ADR-0025 and ADR-0028). None of them is added to this table, or to any `package.json`, before its ADR is accepted. Adopted in Phase 8C (ADR-0035, ADR-0026): pgvector v0.8.7, compiled into `postgres:16-alpine` by `infra/postgres/Dockerfile` (pinned to commit `f37c13f68b57d2c3472b2214fbcff699d6d34876`) as the image `lms-postgres:16-pgvector-0.8.7` that local, CI and staging run; and the embedding model `gemini-embedding-001` at 768 dimensions, called over HTTPS like the chat models, with no SDK. Phase 8D adds no dependency: its filtered searches rely on pgvector's iterative index scans (`hnsw.iterative_scan`, 0.8.0 and later), one more reason the pin holds. Phase 8E adds none either: grounded answers call the chat models the registry lists through the same router and HTTPS adapter, with no SDK, no orchestration library (LangChain and LangGraph stay out, ADR-0025) and no new package. Phase 8F (the closure) adds none either. Groq, the stand-in for Gemini (ADR-0038, 5 October 2026), adds none either: its OpenAI-compatible chat completions are called over HTTPS with the same `fetch`, no SDK.
