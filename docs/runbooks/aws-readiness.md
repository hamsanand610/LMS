# AWS readiness — checklist after Phase 9

Reviewed on 7 October 2026, after Phase 9 (the learning agent) was committed (`369bd8a`) and GitHub
Actions run #34 was green on every job. **Nothing is deployed to AWS**: this is a readiness review and the checklist for the first
deployment, which needs the client's go-ahead. Staging today is one VM with Docker Compose
(`docs/runbooks/staging.md`).

## Checklist for the first AWS deployment

1. The client approves the AWS deployment and its cost.
2. Network: a VPC with public subnets (ALB) and private subnets (API, web, runner host, database).
3. RDS or Aurora PostgreSQL 16 with pgvector ≥ 0.8.0; snapshots on; a parameter group allowing the
   extension.
4. S3 buckets (private, public), CORS for presigned uploads; CloudFront for public files if wanted.
5. The four images by commit SHA: pulled from GHCR with a read token, or mirrored to ECR.
6. Secrets in Secrets Manager or SSM; the task definitions or the instance read them as environment
   variables. No secret in an image, a log or the repository.
7. Services: `web` and one `api` replica (ECS on EC2 or an EC2 host with Compose); the `runner` on an
   EC2 host with Docker and the sandbox image; ALB with ACM certificates; target-group checks on
   `/health/ready`.
8. One-off release task: `prisma migrate deploy`, then the base seed. Back up first (runbook §5).
9. Mail through SES; a verified sender in `EMAIL_FROM`.
10. AI: `AI_PROVIDER=gemini` with a paid key, `AI_DATA_CLASSES=public,course`, the evidence floor,
    `AI_MODEL_COSTS`, a monthly budget; Groq only if its terms are accepted. Flags stay off until
    the client approves each surface.
11. Observability: CloudWatch logs and alarms on 5xx, health, database CPU and storage, the AI
    budget alert.
12. A rollback plan: the previous image tag, and a database snapshot taken before the migration.

## Blockers

None in the code. Before production, three decisions and one external item:

- the client's go-ahead for AWS (account, region, cost);
- one API replica until the in-memory gates move to a shared store (Phase 12);
- a host that can run Docker for the code-execution runner;
- a paid Gemini quota, and for the learner's own data to reach it, its terms recorded (ADR-0041).
